ABOUT

Pinspire is an image discovery and collection application that allows users
to search for images using the Pixabay API, organize images into collections,
edit saved image descriptions, remove saved images, and share public
collections. Collections can be switched between public and private.


TECHNOLOGIES

Frontend:
- React
- TypeScript
- Vite
- Lucide React

Backend:
- Node.js
- Express
- TypeScript

Other:
- Pixabay API
- JSON-based persistent storage


SETUP AND RUNNING THE APPLICATION

Prerequisites:
- Node.js and npm
- A Pixabay API key

1. Clone this repository and enter the project directory.

2. Navigate to the frontend folder:

   cd frontend

3. Install frontend dependencies:

   npm install

4. Create a file named .env inside the frontend folder and add:

   VITE_PIXABAY_API_KEY=YOUR_PIXABAY_API_KEY

5. Start the frontend:

   npm run dev

6. Open another terminal and navigate to the backend folder:

   cd backend

7. Install backend dependencies:

   npm install

8. Start the backend:

   npm run dev

9. Open the localhost URL displayed by Vite in a browser
   (typically http://localhost:5173).


FEATURES

- Search for images using the Pixabay API
- Create collections
- Save images to collections
- View saved images
- Edit saved image descriptions
- Remove images from collections
- Persistent collection storage
- Public/private collection controls
- Share public collections with a unique collection URL
- Responsive user interface
